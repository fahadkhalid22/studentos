# StudentOS Visual Design Bible v1 — Package

This package converts the locked StudentOS visual decisions into implementation-ready design guidance.

Files:
1. `StudentOS_Visual_Design_Bible_v1.md` — complete visual system and design rules.
2. `StudentOS_Design_Tokens_v1.json` — exact colors, gradients, typography, spacing, radii, sizes, motion and breakpoints.
3. `StudentOS_Icon_Registry_v1.csv` — icon inventory covering navigation, global actions, academic modules, AI, settings and system states.
4. `StudentOS_82_Screen_Visual_Map_v1.csv` — screen-by-screen visual treatment for all 82 required screens/states.

Important:
- `StudentOS` is still a temporary codename.
- The visual redesign must preserve the existing product logic and complete prototype flows.
- Rounded Duotone is the preferred icon style. Verify the chosen icon family's license/package availability before implementation.
